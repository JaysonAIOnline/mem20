# Worksheet — JTBD Survey (Step 08)

Send as a short form (Typeform/Sheets). One line per response.

> "When **[situation]**, I want to **[motivation]**, so I can **[outcome]**."

## Questions
1. Situation: When does memory most break down for you?
2. Motivation: What do you want the system to do about it?
3. Outcome: What job are you really hiring memory to do?
4. Frequency (1–5): how often does this happen?
5. Severity (1–5): how painful when it does?

pain"). Rank themes by `sum(Freq × Sev)`. Top themes → Step 12 RICE inputs.
