# mem20 2.1 — Plan & Freeze Note

**Status:** code complete and **frozen** as **2.1.0-rc2** pending the GitHub release. No code
changes until the release is cut and the quadruple QA audit passes.

## What 2.1 adds (this increment)
- **Pluggable integrations.** Blender and Unity are no longer inline in one monolith; they ship as
  separate optional modules:
  - `mcp/tools/blender_tools.py` — `BlenderToolsMixin` (7 tools).
  - `mcp/tools/unity_tools.py` — `UnityToolsMixin` (5 tools).
  - `mcp/tools/integration_tools.py` — filesystem tools (3) + a BLANK TEMPLATE
    (`register_integration_template`) for adding future optional integrations (e.g., Figma).
- **Graceful degradation.** Blender/Unity tools return an informative message when the application is
  absent (env `MEM20_BLENDER_EXECUTABLE` / `MEM20_UNITY_EXECUTABLE`, or on PATH). No hard failure.
- **Standalone packaging.** Added `requirements.txt` (pinned core deps), `requirements-optional.txt`
  (documents the external app integrations), `systemd/mem20.service.template` (placeholder-substituted
  by `install.sh`), and `install.sh` (venv + deps + unit generation).
- **Docs.** README updated: modular layout, optional-integration note, dependencies, and an
  "Adding an optional integration" section.
