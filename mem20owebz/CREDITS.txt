# API Keys to Gather — Jayson Model Bridge

Every key goes in the `.env` file next to `docker-compose.full.yml`.
The bridge (`litellm`) reads these and exposes ~42 models. Empty keys are simply ignored —
only the providers you supply keys for become available.

You have confirmed VERIFIED free-tier access (with payment method on file) to:
  Azure, AWS, Oracle/OCI, and Cloudflare  — these are wired into the bridge config.

## How to use the keys
--------------------------------------------------------------------------------
1. Open `.env` in this folder.
2. Paste each real key next to its variable (replace the placeholder).
3. Save, then restart the bridge:
       docker compose -f docker-compose.full.yml up -d jayson-bridge
4. Verify: the bridge serves more models as you add keys.

## Router groups (auto-failover between providers)
- `fast`     → cheap + low latency (Groq 8B, Gemini 2.5 Flash)
- `balanced` → mid-size general work (Groq 70B, Gemini 2.5 Flash)
- `strong`   → best reasoning (Gemini 2.5 Pro, DeepSeek Reasoner)

## Recommended minimum set
For a strong free setup, get at least:
1. GEMINI_API_KEY
2. GROQ_API_KEY  (or XAI_API_KEY)
3. ANYAPI_API_KEY  (or OPENROUTER_API_KEY)
4. HF_TOKEN

## Security
- Never commit `.env` to git.
- The bridge master_key and WEBUI_SECRET_KEY are already randomized in the config.
- Keep a secure offline copy of your real `.env`.
