# RPG Recipe: Medieval Furniture (Table, Chair, Bench)

**Prefix:** `FUR_`  

## Table
1. Top – Single plane refined with thickness (Solidify) + slight wear bevels.
2. Legs – Curve or carefully extruded posts. Use Array + Mirror for symmetry.
3. Stretchers / rails – connecting pieces with clean joins.
4. Optional: carved details via Boolean or GN.

## Chair
- Similar modular approach: seat, back, legs, stretchers.
- Keep topology light for game use.

## Geometry Nodes
- Wood grain direction attributes
- Metal nail/rivet heads
- Optional cloth drape on seats (separate)

## Materials
Strong wood materials with anisotropy. Separate material for any metal fittings.
