# Advanced Blender Pipeline – Beyond Primitives
### Production-Ready Hard-Surface, RPG Props & Architecture Workflow

**Version:** 3.0  
**Target Blender:** 4.2+  
**Focus:** Expert non-destructive modeling, Geometry Nodes, Python API scripting, clean topology, UVs, baking, materials, LODs, export + extensive RPG & building recipes.

---

## Pipeline Structure

```
01_Project_Setup          → Scene template, units, collections, setup script
02_Naming                 → Strict naming + custom properties
03_Base_Modeling          → Curves, Booleans, topology discipline
04_Geometry_Nodes         → Detail system + recipes + Python generators
05_UV_Bake                → Unwrapping + high-to-low baking
06_Materials              → Layered PBR + attribute-driven + scripts
07_Export                 → glTF/FBX + LOD scripts
08_Example_Asset          → Sci-Fi Thruster full build
09_RPG_Items              → Expanded fantasy props (weapons, armor, furniture, etc.)
10_Buildings              → Medieval architecture + Modern skyscrapers
11_API_Scripts            → Advanced bpy automation & helpers
docs/                     → Overviews + master checklist
```

---

## Quick Start

1. Open Blender 4.2+
2. Run `01_project_setup/setup_scene.py`
3. Follow naming conventions
4. Choose your path:
   - Sci-Fi → Thruster
   - RPG Props → `09_rpg_items/`
   - Architecture → `10_buildings/`
5. Use scripts in `11_api_scripts/` for automation

All techniques remain non-destructive, parameterized, and production-oriented.
