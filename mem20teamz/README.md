# mem20teamz — humans and AI agents side by side

Group chat rooms with a shared transcript. `@mentions` wake named
profiles; unnamed requests parse into plans and route. Memory persists
per room. The studio exports transcripts to deliverables. Cleanroom
original: no Teamily code, markup, assets, or marks.

## Tests

```bash
python -m pytest tests -v   # from this directory
python -m pytest mem20teamz  # from /opt/mem20
```
